ملك الأرقام المميزة — نسخة ويب مجانية
=====================================

محتويات الحزمة:
- index.html: الموقع كامل في ملف واحد، متجاوب مع الهاتف.

قبل النشر:
1) افتح index.html بمحرر نصوص.
2) ابحث عن WHATSAPP_NUMBER = "961XXXXXXXXX"
3) استبدل Xs برقم واتسابك بصيغة دولية من دون + أو مسافات.
4) عدّل مصفوفة listings لتغيير الأرقام والوصف. الأسعار الحالية أمثلة وليست عروضاً حقيقية.
5) افتح index.html بالمتصفح للتجربة.

نشر مجاني:
- أنشئ حساباً على GitHub إن لم يكن لديك حساب.
- أنشئ مستودعاً عاماً جديداً باسم malek-al-arqam.
- ارفع index.html.
- من Settings > Pages اختر النشر من فرع main والجذر /root ثم Save.
- سيعطيك GitHub رابطاً عاماً للموقع بعد اكتمال النشر.

حدود النسخة:
- لا تحتاج إلى قاعدة بيانات أو اشتراك.
- طلبات البيع والاستفسارات تُرسل إلى واتساب.
- الأرقام المعروضة مكتوبة داخل الملف؛ لا توجد لوحة إدارة أو مزامنة تلقائية بين المستخدمين.
- تأكد من الالتزام بالإجراءات الرسمية اللبنانية عند عرض أو نقل ملكية أرقام اللوحات.
